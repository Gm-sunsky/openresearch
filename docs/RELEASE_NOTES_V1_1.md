# AI Research Board V1.1 发布说明

## 卡片打包与整理

- 将一张卡片拖到另一张卡片上，目标卡片会放大提示；松开即可组成卡包。
- 卡包默认只展示当前卡片，减少同一项目大量来源同时铺开造成的拥挤。
- 使用鼠标滚轮、触控横向滑动，或卡包底部的前后按钮切换卡片。
- 长按卡包约 0.65 秒，可将当前显示的卡片拆出。
- 卡片三点菜单支持编辑内容和删除卡片。
- 卡包三点菜单额外支持“拆出当前卡片”和“一键拆分卡包”。
- 拖动卡包时，包内卡片会整体移动并保存位置。

## 数据兼容

V1.1 会直接读取 V1.0 及更早版本的 `research-board.sqlite`，并在启动时自动补齐卡包字段。现有项目、来源、卡片、布局和 API 设置不会被清空。迁移前软件仍会保留上一版数据库安全副本。

## 使用提示

- 卡片进入拖动状态后，长按拆分会自动取消，避免拖动时误拆。
- 卡包只属于当前项目，不会把不同项目的卡片混合在一起。
- 卡包只剩一张卡片时会自动恢复为普通卡片。
