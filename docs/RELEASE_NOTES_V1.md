# AI Research Board V1.0 发布说明

## 三个迭代里程碑

### V0.3.0 — 稳定运行

- API 不可用时使用公开搜索发现候选来源
- 来源发现失败时保留此前候选
- 项目和来源暂停/恢复
- 来源发现与信息检查任务历史
- 数据库上一版安全副本和损坏恢复

### V0.4.0 — 项目 Agent

- AI 生成项目配置，失败时退回本地规则
- AI 对新信息执行相关性、分类、摘要和重要度判断
- 网页前后快照交给 AI 做语义变化整理
- AI 空响应、超时和格式失败不阻断采集
- 无来源项目按计划自动重新发现来源

### V1.0.0 — 完整 Windows MVP

- 白板分类筛选、全文搜索、卡片选择与编辑
- 项目目标、关注范围和频率编辑
- 错误来源一键重试
- 每日自动备份、手动备份和数据目录入口
- SQLite 迁移版本、上一版恢复副本和最近 10 份备份保留
- 安装版与免安装版发布验证

## 升级说明

V1.0 会直接读取旧版 `research-board.sqlite`，启动时自动补齐新字段。原有项目、来源、卡片位置和 API 设置都会保留。升级前也可以从数据目录复制数据库文件作为额外备份。
