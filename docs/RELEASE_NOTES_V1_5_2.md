# OpenResearch 1.5.2

## 中文

- 当前最新软件以 OpenResearch 名称分发，统一侧栏、窗口标题、安装器及应用名称。
- 保留原应用标识、数据目录、数据库文件和语言偏好，支持现有用户升级。
- 提供 Windows NSIS 安装器、Windows 便携版及 macOS Apple Silicon / Intel 便携包。
- 加入 Windows/macOS GitHub Actions 构建与版本标签发布；Mac runner 生成 DMG 安装镜像。
- 补全中文和英文安装、使用、开发、数据安全、发布和限制说明。
- 安装包未签名或公证；Mac 本机运行仍需实机验证。

## English

- Distribute the latest app as OpenResearch, with consistent sidebar, window, installer, and application names.
- Retain the legacy application identifier, data directory, database, and language preference for upgrades.
- Provide Windows NSIS and portable packages plus Apple Silicon / Intel macOS portable ZIPs.
- Add Windows/macOS GitHub Actions builds and version-tag releases, including native Mac DMG images.
- Document installation, usage, development, data handling, release publishing, and limitations in Chinese and English.
- Builds are unsigned and not notarized. Native Mac runtime verification remains necessary.
