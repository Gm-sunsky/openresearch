# AI Research Board V1.2 发布说明

## 核心信息卡片

- 采集到网页或 RSS 后，系统先结合项目名称、目标和关注范围提取核心事实。
- 配置 AI 时，AI 会进一步过滤无关内容，并优先整理状态、日期、地点、期限、票价和已确认变化。
- AI 不可用时，本地规则仍会挑选最相关的事实句，不再把整段网页原始内容直接放进卡片。
- 新生成的核心信息会采用简短分点排版，原始链接仍可通过卡片右下角打开。

## 关键图片

- 支持从 RSS 媒体附件、Open Graph、Twitter 图片字段及网页正文中选择关键图片。
- 会跳过常见 Logo、图标、头像、跟踪像素和尺寸过小的图片。
- 图片加载失败时自动退回纯文字卡片，不影响其他内容。

## 自适应尺寸

- 鼠标拖动卡片四边或四角即可改变尺寸，缩放过程中显示当前宽高。
- 卡片最小为 240 × 170，最大为 640 × 620，避免内容不可用或白板失控。
- 图片仅在卡片具有足够展示空间时出现；尺寸不足时自动隐藏图片并重新分配文字行数。
- 卡包会统一使用同一尺寸；缩放卡包时全部内部卡片同步保存。

## 数据兼容

V1.2 会自动升级 V1.1 及更早版本数据库，新增图片字段但不会清空已有项目、来源、卡片、卡包、布局或 API 设置。旧卡片仍可正常使用和缩放。
