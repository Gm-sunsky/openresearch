# OpenResearch

**简体中文** | [English](README.en.md)

[下载安装包](https://github.com/Gm-sunsky/openresearch/releases/latest) · [报告问题](https://github.com/Gm-sunsky/openresearch/issues)

OpenResearch 是一个本地优先的 Windows 与 macOS 信息项目工作台。用户用自然语言创建长期关注主题，应用把目标整理为项目配置，并在可拖拽白板中持续积累来源、更新、事件和分析卡片。

- 每次更新都会按完整研究矩阵主动执行一次全网搜索，不再只读取已经保存来源的首页
- AI 返回空卡、占位文字或无来源索引时，软件会强制使用本地证据重建卡片
- 确实缺少证据时会显示已检查材料数、监控对象和覆盖缺口，不再使用“当前来源未提供可确认的信息”掩盖原因
- 内置 `general-information-research` 研究技能，以独立 `SKILL.md` 统一规定搜索、证据分层、交叉核验、历史比较和输出质量
- 每次调用模型前都会把内置技能与当前项目编译成项目技能实例，明确对象、关注项、研究矩阵、输出语言和证据截止时间
- AI 输出必须包含每个“关注项 × 监控对象”的覆盖状态、结论和来源索引；缺项、空占位或无来源确认会触发技能合规修复
- 模型修复仍不完整时，程序会确定性补齐覆盖记录，并在卡片中显示证据截止时间和可信度
- 更新任务记录会保存本次使用的研究技能名称与内容摘要值，便于确认软件确实加载了技能
- 右侧变化与冲突记录支持直接点击定位对应卡片，并自动切换到对应更新批次
- 目标位于卡包内部时自动切换到正确页码；定位后居中显示、打开卡片详情并短暂高亮
- 冲突关联卡片已清理时会尝试定位历史卡片，否则明确提示卡片已经删除
- 综合整理可恢复兼容 API 返回的顶层数组、Markdown 代码块、嵌套结果、尾逗号和字符串内换行

## 项目更新与信息层级

在侧栏勾选需要更新的项目，再点击更新按钮。点击项目名称只切换查看内容；未勾选项目不会因其他项目更新而被处理。新建和旧版迁移的项目默认不勾选，暂停项目不参加定时更新。正在运行的项目各自显示进度，切换项目不会把旧结果写入当前白板。

创建项目的预览页、项目设置中可选择信息层级：

- **核心事实**：直接回答关注项，例如活动时间，省略原因与扩展背景。
- **相关背景**：核心答案加上有证据的一层原因、条件或相关事项。
- **深入关联**：进一步介绍有关联依据的同期事项及背景，最多扩展两层；缺少依据的原因保持未知。

层级按项目保存，下次更新生效。三档正文预算分别约为480、1100、2200字；多对象名称较长时优先保留全部对象的核心答案，必要的覆盖和来源说明会保留。历史卡片保留原有内容。

搜索和采集使用受限并发，在保留相同查询和证据的延迟注入测试中，来源发现等待时间降低75%，采集等待时间降低约82%。这些是可复现基准，不代表所有网络或模型服务的实际耗时。

## 开发运行

要求：Node.js 20.19 或更新版本，Windows 10/11 或 macOS 11 及更新版本。

```powershell
npm ci
npm run dev
```

生产构建与验证：

```powershell
npm run lint
npm run build
npm run dist:win
npm run dist:mac:portable
```

安装包输出到 `release/V1.5.5/OpenResearch Setup 1.5.5.exe`。
免安装压缩包输出到 `release/V1.5.5/OpenResearch Portable 1.5.5.zip`，完整解压后运行其中的 `OpenResearch.exe`。

macOS 免安装版输出为 `release/V1.5.5/OpenResearch macOS arm64 1.5.5.zip`（Apple 芯片）和 `release/V1.5.5/OpenResearch macOS x64 1.5.5.zip`（Intel）。解压后直接打开 `OpenResearch.app`；未签名测试版首次打开时请按住 Control 点击应用，选择“打开”。后续版本会自动创建各自的 `release/V版本号/` 目录。

## 架构

```text
src/                    React 界面、白板和共享 IPC 契约
electron/preload/       只暴露白名单桌面 API
electron/main/          SQLite、IPC、采集、调度和窗口生命周期
tests/                  规则、解析、调度和数据库回归测试
docs/                   产品与交互规格
```

数据保存在 Electron 的用户数据目录中，文件名为 `research-board.sqlite`。设置页可直接打开数据目录或创建备份；软件每天自动保留一份备份，最多保留最近 10 份。AI 密钥不是启动前提；项目创建、公开搜索兜底和采集均可在未配置 AI 时运行。配置密钥后，Agent 会进一步执行来源发现、相关性判断、摘要、分类和变化整理；兼容服务可使用 Responses 或 Chat Completions 协议。

桌面网络请求使用 Chromium 网络栈，会自动读取 Windows 或 macOS 的系统代理、PAC 和常见代理认证配置。远程 API 仍然必须使用 HTTPS，本机兼容服务可使用 `localhost` HTTP。

API 与来源发现的边界、接口和安全策略见 [API 与来源发现设计](docs/API_AND_SOURCE_DISCOVERY_V0.2.md)。

从项目拆解、检索矩阵、证据分层、交叉核验到二次信息输出的完整规范见 [通用信息搜集流程 V1](docs/GENERAL_RESEARCH_WORKFLOW_V1.md)。

新媒体账号搜索使用 Responses API 的 `web_search` 工具。普通网页和 RSS 不依赖该工具；X、Instagram、YouTube、B站等搜索型来源需要配置支持网页搜索的 API 与模型。

## 已知边界

- 网页提取目前采用 metadata 与清洗后的文本快照，复杂单页应用可能只能获得有限内容。
- 公开搜索兜底依赖搜索服务的可访问性；候选仍建议由用户确认后添加。
- 监控对象目前从项目名称、说明、目标中的名称列表和书名号/引号内容自动提取；描述非常抽象时会回退为项目名称，建议在项目说明中列出具体对象。
- 安装包尚未进行商业代码签名，Windows 可能显示未知发布者提示。
- 暂不包含账号、云同步、多人协作和社交媒体专用爬虫。

完整设计规格见 [Windows MVP 设计方案](docs/AI_Research_Board_Windows_MVP_V1.md)。

## GitHub 项目与跨平台发布

当前版本为 **1.5.5**。本地 Windows NSIS 安装包及 Windows、macOS arm64/x64 便携包输出在 `release/V1.5.5/`。上传完成后从本仓库 Releases 下载对应平台版本。

macOS 原生安装包需在 Mac 上运行 `npm run dist:mac`，生成 Apple Silicon 与 Intel 的 DMG、ZIP，输出到 `release/`。已有 `.github/workflows/release.yml` 会在 Windows 与 macOS 分别完成 lint、类型检查、测试和打包。手动触发可取得构建产物；推送与 package.json 一致的版本标签（如 `v1.5.5`）会在两平台成功后发布 GitHub Release 和 SHA256 校验值。工作流需要启用 GitHub Actions，并受账号用量限制。

### 安装、数据与升级

Windows 安装版运行 `OpenResearch Setup 1.5.5.exe`；便携版完整解压后运行 `OpenResearch.exe`。Mac 请选择与芯片匹配的 ZIP，解压后把 `OpenResearch.app` 移入 Applications；DMG 则打开后拖入 Applications。

更名保留原应用标识与数据目录：Windows 为 `%APPDATA%/AI Research Board`，macOS 为 `~/Library/Application Support/AI Research Board`；数据库文件仍是 `research-board.sqlite`。设置页可打开数据目录或备份。原语言偏好继续保留。

安装包尚未代码签名或 Apple 公证。Windows 可能显示未知发布者；macOS 请按系统“隐私与安全性”提示允许可信应用，勿全局关闭安全防护。Windows 上的 Mac ZIP 结构校验不能替代真实 Mac 启动测试。

### 使用步骤

1. 新建项目，明确列出监控对象和关注项。
2. 审核发现的候选来源后添加，也可手动添加 RSS、网页或搜索型账号。
3. 勾选侧栏需要更新的项目，再执行更新；点击项目名称仅切换视图。
4. 如需 AI 整理，在设置中配置 HTTPS 地址、协议、模型和密钥。
5. 查看卡片引用与证据缺口，核对关键结论。

本地存储不意味着所有处理离线：检索和 AI 请求会向对应服务发送查询及必要材料，费用由提供商决定。请勿上传 API 密钥、数据库或私人项目数据。

### 问题反馈与许可

反馈请提供系统、芯片架构、版本、复现步骤和去除敏感信息后的任务诊断。提交改动前运行 `npm run lint`、`npm run build`。目录结构及设计边界见前文与 docs。

目前未授予开源许可证；上传 GitHub 不自动授予修改或再分发授权。
升级时也会检查旧 ai-research-board 数据目录；如果原数据库位于该目录，将继续使用它。

## 阅读完整资料

双击卡片或点击卡片上的完整查看按钮，即可阅读保存的完整整理正文和图片。滚轮或上下方向键滚动，左右方向键或顶部按钮切换卡包资料页，Esc 关闭。卡片只显示独立的精简概述和有实际图注证据支持的核心配图；无说明或关联待确认的图片保留在资料窗口。旧版本已经丢弃的文字需重新更新才能重新整理。

输入异常的排查、已确认原因和验证边界见 [1.5.5 版本说明](docs/RELEASE_NOTES_V1_6_3.md)。
